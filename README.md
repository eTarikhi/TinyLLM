# llm-from-scratch skill

Reusable skill for an AI coding agent helping you create and train a language model from random initialization.

## Contents

- `SKILL.md` — core instructions, workflow, engineering gates, sources and deliverables.
- `references/reading-list.md` — curated research and implementation links with notes.
- `templates/experiment-plan.md` — copyable template for tracking training runs.

## Use

Install or copy the folder into the skill directory supported by your agent. If the agent supports skills with a `SKILL.md` entry point, use this folder as the skill. Before substantial training, read current upstream docs, check licenses for the selected data, and run the single-device pilot and tests.
